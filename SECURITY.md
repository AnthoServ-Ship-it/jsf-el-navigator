# Seguridad

## Versiones con soporte

La versión publicada más reciente recibe correcciones de seguridad.

## Reportar una vulnerabilidad

No publiques información sensible en una incidencia pública. Contacta primero al
autor **anthoserv** mediante un canal privado y proporciona:

- versión de la extensión;
- versión de Visual Studio Code;
- descripción del impacto;
- pasos mínimos para reproducirlo;
- archivos de ejemplo sin información empresarial confidencial.

El proyecto no incorpora telemetría, no envía código fuente a servicios externos y
realiza el análisis localmente dentro del workspace abierto.
